6. DATABASE CHANGES
================================================================================

NEW TABLE: t_role
  - Columns: id, name, description, is_enabled, create_time, update_time, is_deleted
  - Primary Key: id
  - Unique Key: uk_name (on name column)
  - Indexes: idx_is_enabled, idx_create_time
  - Engine: InnoDB
  - Charset: utf8mb4

EXISTING TABLE: t_user_role (no schema changes, only new methods)
  - Tracks username-to-role relationships
  - Used for user authentication
